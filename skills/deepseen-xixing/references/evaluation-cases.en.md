# Development walkthrough cases (fictional)

| Input or action | Expected |
| --- | --- |
| Summary only | Summarize; do not force skill creation or a trial. |
| Improvement requested with material | List what was read, applicability, a narrow reversible trial and unverified items. |
| Source link inaccessible | Report the gap; do not pretend to have read it. |
| Source fingerprint mismatch | Exit 2 and report the changed source hash, not a missing file. |
| Missing or out-of-scope file | Exit 2 and report missing file or out-of-scope path. |
| Advice only | Do not change production or contact others without authorization. |

These public development cases are not independent effect tests or business results.
