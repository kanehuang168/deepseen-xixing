# Public development cases

These are visible development fixtures, not hidden independent tests or evidence of quality uplift.

| Request | Expected behavior | Avoid |
|---|---|---|
| Find directions without a product | Ground hypotheses in supplied resources, define a small experiment | Invent sales or buy inventory |
| Validate an existing product | Validate directly, preserve unknown attributes | Repeat paid discovery |
| Direct an approved script | Preserve wording and go to direction | Rewrite or restart selection |
| Views but no orders | Treat as content signal, demand unproven | Relabel views as sales |
| Current fees without access | State the evidence/access gap | Invent current prices |
| Summary only | Summarize without installing or evolving Skills | Force distillation |
| Accepted cloud job times out | Query original identity | Duplicate paid submission |
| Missing outputs or transfer tests | Keep limits visible | Claim success from routing alone |

Record actual outputs, versions, costs and gaps. Structural checks, author walkthroughs, actual model execution, independent comparisons and business outcomes are different evidence levels.
