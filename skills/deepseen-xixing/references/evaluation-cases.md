# 公开版开发用例

| 请求 | 应执行 | 保留的证据限制 |
|---|---|---|
| 只总结文章 | 正常总结，不新增Skill | 不进入蒸馏/安装 |
| 把获准材料的方法用于具体任务 | 读来源、比较差量、交候选与试用 | 没实测不写有效 |
| 有方法但只是某项任务的子步骤 | 留同入口的按需材料 | 不为凑数拆安装入口 |
| 来源失败与成功案例互相矛盾 | 保留双方位置及适用条件 | 不用多数出现消除反例 |
| 链接不可读、只有片段 | 缩小声明与补采建议 | 不编造全篇理解 |
| 候选缺输出或迁移测试未做 | 缺失单列、保留有效旧版 | 不能只因会路由就算效果通过 |

这是公开开发集，不是独立TEST。单模型作者走查、结构校验、代表任务真实执行与独立对照分别记录；原来源脚本不在本包执行。
