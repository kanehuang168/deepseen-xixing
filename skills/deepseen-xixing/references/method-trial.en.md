# Method trial record

Reference the user's existing task/files rather than creating another cloud authority. Record the target and observable success, inputs/version, current approach/result, proposed small change and evidence, applicability/failure conditions, cost/authorization boundary, actual experiment outputs, previous-success regression, unknowns and rollback conditions.

A source opinion supports a trial, not an effectiveness claim. Label unperformed work and examples honestly. Complete paperwork is not method validation. Share only the current step's necessary inputs, not all source material or chat.
