# 自编样例的交付去向

全部是候选演示，不是经过独立模型对照的通用方法。

## scope

候选DEMO-SCOPE：输入是待比较报表。先识别统计范围，分开不同口径，再交付可比较的组及缺口。只有分组正确的实际回执才能支持试用；缺字段不推断相同。

## missing

候选DEMO-MISSING：输入有缺失成交字段，输出保留未知并阻止依赖该字段的比例。用缺失、零值和完整数据分别测试，不把结构检查当业务效果。

## reference

“重视复盘”保留在参考说明中，不单独拆出一个安装入口。

## excluded

保证增长十倍缺乏证据，不作为可执行承诺。未来若有明确范围和可复核结果，可以重新评估，不因句子出现就自动吸收。
